# comp163_assignment_4
# This is a simulation of college decisions where the user acts as an advisor for the student.
# The user must pick a difficult in course loads (Easy, Normal, or Hard) and also pick a study.
# The system will give suggestion immediately based on the student's intial stats of a 3.8 GPA and 50 social points.
# The coding script consists of conditionals, branching, and logical operators that are used to calculate the student's college status.
# The outcome of the user's choices are displayed in the "FINAL ANALYSIS" section of the simulation.
# Google Gemini was used in assistance for this assignment to fix errors and make sure code was running smoothly.
